# Документация проекта

## Описание базового синтаксиса записи и форматирования

Проект использует следующие технологии и синтаксис:

1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` 
для улучшения читаемости отчетов.

---

## Инструкция по запуску тестов для формирования отчета Allure

1. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите тесты с генерацией отчета Allure:
   ```bash
   pytest --browser=firefox --alluredir=./allure-results
   ```


## Инструкция по просмотру сформированного отчета Allure

1. После завершения тестов, чтобы просмотреть отчет, выполните команду:
   ```bash
   allure serve ./allure-results
   ```

   Эта команда запустит локальный сервер и откроет отчет в браузере.

2. В отчете Allure вы увидите:
   - **Название теста**: `Тестирование калькулятора`.
   - **Описание теста**: Операция сложения при задержке '45'.
   - **Шаги теста**:
     - Открытие страницы калькулятора.
     - Установка задержки 45 секунд.
     - Нажатие кнопок ['7', '+', '8', '='].
     - Ожидание результата '15'.
     - Получение результата.
     - Проверка, что результат соответствует ожидаемому.
   - **Результат**: Успешное выполнение или ошибка с указанием ожидаемого и фактического результата.

   - **Название теста**: `Покупка в интернет-магазине`.
   - **Описание теста**: Чтобы купить товар пользователь должен авторизоваться,
   - положить товары в корзину, заполнить форму заказа.
   - **Шаги теста**:
   - Открытие страницы авторизации.
   - Авторизация пользователя.
     - Очистить поле ввода.
     - Ввести логин пользователя.
     - Очистить поле ввода.
     - Ввести пароль пользователя.
     - Нажать кнопку авторизации.
   - Открытие главной страницы магазина.
   - Получение списка товаров.
   - Добавление товаров в корзину.
     - Поиск товара по его названию.
     - Добавление товара из списка в корзину.
     - Поиск товара по его названию.
     - Поиск товара по его названию.
     - Добавление товара из списка в корзину.
     - Поиск товара по его названию.
     - Поиск товара по его названию
     - Добавление товара из списка в корзину.
     - Поиск товара по его названию.
   - Переход на страницу корзины.
   - Получение списка товаров в корзине.
     - Проверка количества добавленных товаров в корзину.
   - Переход по кнопке на страницу оформления заказа.
   - Заполнение формы оформления заказа.
     - Очистить поле 'Имя'.
     - Ввести значение в поле 'Имя'.
     - Очистить поле 'Фамилия'.
     - Ввести значение в поле 'Фамилия'.
     - Очистить поле 'Почтовый индекс'.
     - Ввести значение в поле 'Почтовый индекс'.
   - Отправка формы кликом по кнопке.
   - Получение стоимости заказа.
   - Проверка: Сравнение ожидаемой суммы заказа с фактической суммой заказа.
   - **Результат**: Можно скачать файл 'Результат проверки суммы' 
   и список найденных товаров на странице 'stdout'.
